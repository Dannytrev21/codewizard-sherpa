### Decisions surfaced for the validator

The story spec made three assumptions that didn't hold on-the-ground. Each
was resolved in spirit and documented:

1. **AC-6.a allowlist incompleteness.** The story names four allowlist
   entries; S1-01 actually shipped three more files (`types/errors.py`,
   `types/parsers.py`, `py.typed`) inside the kernel scope. Adding them
   to `_KERNEL_ALLOWLIST` with `# adr: S1-01` comments is the spirit-faithful
   resolution — the fence catches FUTURE drift; existing reality is
   baselined. The walker file `src/codegenie/_phase3_fence.py` (this
   story's addition) is also allowlisted.

2. **Scope brace-expansion ambiguity.** The story's path expression
   `src/codegenie/{,probes/,...}/**` literally expands to
   `src/codegenie/**` (the leading `,` is an empty slot). That would put
   `plugins/` and `transforms/` in scope — the opposite of intent.
   `_is_in_kernel_scope()` explicitly excludes the two Phase 3 new
   packages via `_TOP_LEVEL_PHASE3_PACKAGES = {"plugins", "transforms"}`.

3. **`as_packages = true` is non-negotiable for the Phase 3 contracts.**
   Phase 0's `codegenie (__init__)` contract uses `as_packages = false`
   for a deliberate cold-start reason; the Phase 3 contracts are about
   *submodule* coverage. `test_phase3_importlinter_contracts_shape.py::
   test_contract_uses_as_packages_true` pins this so a "cleanup" PR can't
   silently downgrade.

### Lessons for `_lessons.md`

1. **Story specs that pre-name future filenames can drift before the
   filenames land.** S1-01 introduced `errors.py` and `parsers.py` that
   the S1-05 allowlist didn't anticipate. When implementing a kernel-
   frozen fence retroactively, audit current reality first, then code
   the allowlist — the fence catches FUTURE drift, not historical adds.
2. **`python -m <package>` requires `<package>/__main__.py`.** Multiple
   real packages (e.g., `import-linter`) ship only console-scripts. When
   writing a subprocess-based fence test, prefer the `sys.executable.parent
   / "<script>"` path with `shutil.which` fallback; `pytest.fail` if both
   fail. Never silently skip — the gate is the gate.
3. **Brace-expansion in story-spec path expressions is ambiguous.**
   `src/codegenie/{,probes/,coordinator/,...}/**` looks scoped but the
   leading `,` expands to an empty member, collapsing to `src/codegenie/**`.
   Always cross-check the listed dirs vs. the intent; document the
   exclusion list explicitly in code.
4. **The kernel-frozen fence reads `git diff baseline..HEAD`, not the
   work tree.** AC-7.b planted-violation evidence for it requires a real
   commit (or AC-6.c-style synthetic injection via dependency-injected
   diff source). Don't conflate "the walker fires on planted input" with
   "the live fence catches uncommitted planted edits" — those are
   different surfaces and the story spec implicitly accepts the
   in-suite parametrized guards (AC-7.a) as load-bearing.
