### Refactor decisions (design-patterns lens)

- **Registry pattern** — the canonical fit; mirrors `RecipeRegistry`
  (`plugins/recipe_registry.py`) verbatim for the `register`/`get` surface
  and the typed-error-marker shape (`CodegenieError` subclass, typed
  `.transform_id`, duplicate message naming both `module.qualname` origins).
- **Dependency inversion** — engines receive the registry by constructor
  injection (S5-02/S5-03); the registry knows nothing of engines.
- **Newtype key** — keyed by `TransformId`, never raw `str` (ADR-0010).
- Deferred (Rule 2): no `all()` enumeration, no `_reset_for_tests()` (a
  fresh per-test instance makes a reset hook unnecessary — this registry is
  per-workflow, not a process-wide singleton), no `default_*` singleton.
  `_origins` retained — it is load-bearing for the duplicate message.
