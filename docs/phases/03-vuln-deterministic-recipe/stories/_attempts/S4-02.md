### Design-pattern notes

- **Hexagonal / Ports-and-Adapters (DP-A).** The Adapter
  (`BwrapAdapter`) lands here as the Linux substrate; the macOS Adapter
  (`SandboxExecAdapter`, S4-03) and Phase 5's `FirecrackerAdapter` /
  `DinDAdapter` substitute via the same Port with zero changes to
  callers. The Protocol is intentionally NOT `@runtime_checkable` —
  structural typing at type-check time only.
- **Tagged union / sum type (DP-B).** Three discriminated unions in
  play: `JailedSubprocessResult` (six variants after this story's
  `JailSetupFailed` extension); `JailedEnv` (NpmEnv | GitEnv, S4-01);
  `NetworkPolicy` (DenyAll | RegistryAllowlist, S4-01). Adapter
  dispatches with `match` + `assert_never` — never `isinstance`
  ladders. AC-25's subprocess-mypy fence enforces this at type-check
  time.
- **Smart constructor (DP-C).** `JailSetupFailed.reason` is a
  `Literal[5 closed strings]` — invalid reasons unrepresentable. The
  six BPF instructions in `_seccomp.build_filter` are pinned to the
  six-element `Syscall` `StrEnum`; non-Syscall inputs fail mypy at the
  call site.
- **Pure functional core / imperative shell (DP-D).** `_build_bwrap_argv`,
  `_classify.classify_outcome`, `_seccomp.build_filter`, `_extract_hosts`
  are all pure. `BwrapAdapter.run` is the only impure code in the
  module (chokepoint call, file open, cgroups read, netns syscall).
- **Stateless Adapter (DP-E).** Zero module-level mutable globals.
  Constants live as `Final`-typed immutables. Concurrent `.run()` calls
  allocate uniquely-named netns names (AC-20 Strategy A — per-call
  isolation; no instance-level lock or throughput hit).
- **Newtype identifiers (DP-F).** `Syscall(StrEnum)` discriminates
  syscall names from raw strings at every type-check site;
  `_BLOCKED_SYSCALLS: Final[frozenset[Syscall]]` propagates the
  type.

### Refactor decisions

- **Did NOT add a `@register_jail` registry.** Substrate selection
  happens at orchestrator construction time, not request time;
  constructor injection (`RemediationOrchestrator(sandbox: SubprocessJail
  | None = None)`) is the right shape. Adding a registry would add
  ceremony without paying rent (Rule 2). Story-level note pinned this.

  import; the six syscalls are a fixed list. No ADR amendment required.

### Cross-story lessons

- **`get_type_hints` strips `Annotated[...]`.** `JailedSubprocessResult
  = Annotated[Union[...], Field(discriminator="kind")]` — the
  `Annotated` wrapper is what carries the discriminator metadata.
  `get_type_hints(fn)["return"] is JailedSubprocessResult` will be
  `False` unless you pass `include_extras=True`. Future stories pinning
  a Port's return annotation should follow this precedent.
- **mypy treats `sys.platform != "linux"` as a constant on darwin.** A
  guarded-early-return shape (`if sys.platform != "linux": return ...;
  <linux code>`) reports the linux code as `Unreachable` under `mypy
  --strict` when type-checking on darwin. Fix: invert to `if
  sys.platform == "linux": <code>; return <default>`. Same pattern bit
  S4-01's mypy-negative test path historically.
- **Hypothesis function-scoped fixtures need `suppress_health_check`.**
  `@given` + `tmp_path` triggers `HealthCheck.function_scoped_fixture`.
  Pattern: `@settings(suppress_health_check=[HealthCheck.function_scoped_fixture],
  ...)`. The fixture is not reset between Hypothesis-generated inputs
  — if the test mutates fixture state, this is wrong; for capture-style
  tests (no fixture mutation), the suppression is correct.
- **Adding a sum-type variant is "additive widening" per S4-01's policy.**
  Step 9 risk #4 explicitly permits new variants + golden regen + ADR
  amendment. The exhaustiveness-AST fence + the variant-count
  assertion both need updating; the subprocess-mypy negative fixture
  becomes *stricter* automatically (missing one or more arms still
  fails mypy).
- **`os.pread` to inspect an open seccomp fd.** When you want to read
  the bytes hand-built into a temp file that the adapter still has
  open, use `os.pread(fd, count, 0)` rather than seek/read — leaves
  the cursor untouched and works without a path. Used in AC-17's
  determinism test.
