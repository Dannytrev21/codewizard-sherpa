### As-built drift resolutions

The story is HARDENED and accurate. Five sub-points needed an as-built call;
all are documented here and in the module docstring (Rule 7 — surface, pick
one, do not average).

1. **`parse_registry_url` does not enforce a trailing slash.** The landed
   `codegenie.types.parsers.parse_registry_url` (S1-01) accepts
   `https://registry.npmjs.org` (no trailing `/`). AC-Load-3 +
   `test_from_yaml_invalid_registry_url_no_trailing_slash` require the loader
   to reject it. Resolution: `from_yaml`'s per-URL step calls
   `parse_registry_url` **and** an explicit `url.endswith("/")` check — the
   policy file requires a canonical trailing-slash origin. This *strengthens*
   the policy check rather than weakening it (story Refactor note). S1-01
   follow-up: `parse_registry_url` itself could be tightened to require the
   slash; not done here (out of scope, surgical).

2. **Build backend is hatchling, not setuptools.** Validation note #5 says
   `[tool.setuptools.package-data]`; the project uses `hatchling`. Hatchling
   already ships every non-Python file under `packages = ["src/codegenie"]`
   (the existing `src/codegenie/schema/*.json` assets prove it). Added an
   explicit `[tool.hatch.build.targets.wheel] artifacts` entry so a future
   build-config change cannot silently drop the YAML. Verified by building a
   wheel: `codegenie/transforms/policy/lockfile-policy.yaml` is present.

3. **`LOCKFILE_POLICY_PATH` resolution.** The TDD-plan "Green" section (story
   lines ~734-741) shows `Path(codegenie.__file__).parent / ".." / ".."`; the
   authoritative Validation-notes #5 + AC-Surface-3 + Implementation-outline §4
   mandate `importlib.resources.files(...)`. Followed the latter — it is
   wheel-correct (the `..`/`..` form breaks under a wheel install).

4. **YAML parser: raw `yaml.safe_load`, not the `safe_yaml` chokepoint.** The
   story (outline §8.2) prescribes `yaml.safe_load`. The repo's
   `codegenie.parsers.safe_yaml` chokepoint translates every `yaml.YAMLError`
   into a *stateless marker* exception, which destroys the `problem_mark`
   line/column data `PolicyYamlSyntax` carries. The chokepoint's defences
   (symlink refusal, billion-laughs) target hostile *analyzed-repo* input;
   this policy file is codegenie-owned and trusted. The deliberate choice is
   documented in the module docstring.

5. **Single-arm discriminated union.** `PolicyViolation =
   Annotated[UnauthorizedRegistry, Field(discriminator="kind")]` (AC-Union-1
   verbatim) constructs cleanly under Pydantic v2 `TypeAdapter` — round-trip
   and reject-unknown-`kind` both pass. No fallback to a plain alias needed.
