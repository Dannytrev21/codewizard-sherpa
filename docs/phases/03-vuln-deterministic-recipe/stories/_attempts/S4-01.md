### Design-pattern notes

- **Hexagonal / Ports-and-Adapters (DP-A).** The Port (`SubprocessJail`) lands here; the two interim Adapters (S4-02 `BwrapAdapter`, S4-03 `SandboxExecAdapter`) and Phase-5 substitution (`FirecrackerAdapter` / `DinDAdapter`) are all downstream. The Protocol is deliberately *not* `@runtime_checkable` to prevent `isinstance(jail, SubprocessJail)` foot-guns.
- **Discriminated unions (sum types) over booleans (DP-B).** 3 discriminated unions in one module: `JailedSubprocessResult` (5 variants), `JailedEnv` (2 variants), `NetworkPolicy` (2 variants). All use the codebase's canonical `Annotated[Union[...], Field(discriminator="kind")]` shape; matches every prior umbrella in `outcomes.py`.
- **Smart constructor (DP-C).** `RegistryAllowlist._hosts_non_empty_and_https` is the smart constructor for the `RegistryUrl` strict-`https://` semantic that the `NewType` documents but cannot enforce at runtime. Two other smart constructors: `_wall_time_finite` (Completed) and `_finite` (TimedOut), both pinning `math.isfinite` because Pydantic's `Field(ge=0)` admits +Inf.
- **No extension trapdoor (DP-D).** `NpmEnv` and `GitEnv` carry zero public fields beyond `kind`; the safety keys (`npm_config_ignore_scripts`, `GIT_TERMINAL_PROMPT`, `GIT_ASKPASS`) are emitted inside `to_env_mapping` from string literals. AC-7c / AC-8 fence this at the field-name level.
- **Functional core / imperative shell (DP-E).** Every model is `frozen=True`; there is no mutable state in this module; the `_RESULT_ADAPTER` module-cached `TypeAdapter` is the only allocation that survives import. Adapters (S4-02 / S4-03) own the imperative shell.

### Refactor decisions

- **Did NOT decorate the Protocol with `@runtime_checkable`.** ADR-0006 §Decision and AC-2 both demand the negative; the rationale ("Protocol runtime check ignores method signatures") is in the class docstring.
- **Did NOT inline `assert_never` into the module.** Exhaustiveness lives in tests; this is a Phase-3-Step-1 contract surface and should not depend on `typing.assert_never` at runtime.
- **Did NOT abstract a shared "finite float validator".** Two callers (`Completed.wall_time_s` and `TimedOut.{budget_s, elapsed_s}`) — rule-of-three not yet satisfied. The third call site (Phase 5 `FirecrackerAdapter` likely surfaces one for memory ballooning) would justify a `codegenie.transforms._validators.finite_float` helper.
- **Did NOT add a `from_env_mapping` inverse helper.** The Port flow is *spec → adapter → env_mapping → subprocess*; the reverse direction has no consumer (the adapter consumes the dict it builds). Speculative-API rule kicks in.

### Cross-story lessons

- **`typing.Protocol` introspection — `__protocol_attrs__` not `__abstractmethods__`.** CPython 3.12+ populates `__protocol_attrs__` with the names of declared protocol members; `__abstractmethods__` stays empty unless members are explicitly `@abstractmethod`-decorated. Story drafts that pin Protocol-member presence via `__abstractmethods__` will fail at green time. Future stories should follow the precedent set here and use `__protocol_attrs__`.
- **Docstrings get grepped by AST fences.** The Phase-3 `Any`-fence (AC-12 regex + the global `test_no_any_in_plugin_surface.py`) walks `inspect.getsource(mod)` which *includes* the module docstring. Mentioning `dict[str, Any]` or `asyncio.create_subprocess_exec` in prose triggers grep-style fences elsewhere (e.g., `test_only_exec_module_calls_create_subprocess_exec`). Default to rephrasing prose ("no untyped dict", "a thread-pooled blocking spawn") rather than fighting the fence.
- **Pydantic v2 `frozenset[NewType]`.** `frozenset[RegistryUrl]` works natively under `frozen=True`; no `model_validator` or custom serializer needed. The strict-`https://` semantic is enforced via `@field_validator("hosts", mode="after")` — the smart constructor for the `NewType` at the boundary.
