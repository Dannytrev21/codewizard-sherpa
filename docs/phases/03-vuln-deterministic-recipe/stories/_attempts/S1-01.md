### Refactor decisions (design-patterns lens)

- **Helper closure over registry** (Rule 2). `_regex_parser` is closed-over by 12 module-private callables — `_cve_match`, `_ulid_match`, `_hex64_match`, etc. — and the public parsers wrap those. A `@register_parser` decorator was explicitly **rejected** (story Notes D-F5: "parsers are kernel-tier, closed-set, not user-extensible"). The current shape passes AC-18 (one `.fullmatch(` in the file) without introducing a runtime registry.
- **NFKC-mutation guard** (defensive). `parse_branch_name` and `parse_package_id` reject any input whose NFKC-normalised form differs from the original. This is stricter than "reject after-normalisation non-ASCII" alone — it stops homoglyph attacks where an attacker submits a Unicode form that NFKC-collapses to a legal-looking ASCII string the caller didn't intend.
- **Empty `py.typed` marker** at `src/codegenie/py.typed`. Required by AC-4c: the subprocess-mypy meta-test writes a temp file that `import`s `codegenie.types.identifiers`; without the PEP-561 marker, mypy emits `[import-untyped]` before checking the swap. The marker is harmless (codegenie isn't published) and unlocks downstream typed-import support if it ever is.
- **Phase-2 carryover names included in `__all__`.** Pre-Phase-3 the module exported 8 names but `_NEWTYPE_REGISTRY` is required to mirror `__all__` exactly (AC-15) — the registry includes the Phase-2 names with `(ADR-0010 lineage; ADR-0033)` documentation.

### Rule-7 surfaces

- **Story originally prescribed `src/codegenie/types/result.py`.** Implementation correctly imports from the canonical `codegenie.result` (Phase-2 S1-04). The validator hardened the story to forbid the fork; the executor honoured the hardened version. No fork created.
- **Arch `phase-arch-design.md §Data model` shows `PackageId.parse(s)` classmethod.** `NewType` cannot host classmethods; the executor shipped free-function `parse_<x>(s)` per the story's "Arch ↔ story API drift" note. Surfaced in the parser module docstring.

### Lessons

1. **py.typed is a load-bearing 0-byte file when subprocess-invoking mypy.** First implementation attempt of AC-4c failed because mypy issued `[import-untyped]` before reaching the swap diagnostic. Adding `src/codegenie/py.typed` made all 14 negative + 1 positive subprocess assertions pass. Future stories that subprocess-mypy a tmp file importing `codegenie.*` get this for free.
2. **AC-18 (single-fullmatch invariant) drove a cleaner closure catalog** than the "5 named parsers go through the helper, others inline" shape from the story body. Routing every regex match through `_regex_parser` made adding a new regex-shaped parser a one-line change (Open/Closed).
3. **Pre-existing `test_lint_imports_canary.py` failures are PATH-bound** — they pass when `.venv/bin` is on `PATH` (via `PATH="$(pwd)/.venv/bin:$PATH" pytest`). Recorded so future executors don't chase it.
