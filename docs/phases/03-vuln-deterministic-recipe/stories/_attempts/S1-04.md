### Decisions made during execution

1. **Bare-`Transform()` TypeError gate via `__new__`.** The ABC pattern
   the story requires (class-level annotations only, no
   `@property @abstractmethod`) means ABCMeta's default abstract-method
   block does not fire on its own. AC-8a demands `Transform()` raises
   `TypeError`. Solution: override `__new__` and check `cls is Transform`.
   Subclasses pass through untouched. This preserves the
   `Probe(ABC)` precedent for the four contract attributes while still
   blocking direct instantiation. Documented in the ABC docstring + the
   `__new__` body comment.

2. **`__new__` over `__init__` for the gate.** `__init__` would force
   subclasses to call `super().__init__()` (and they'd inherit the raise).
   `__new__` short-circuits cleanly when `cls is Transform`.

3. **Non-UTC tz normalized via `astimezone(UTC)`, not rejected.** The
   story allowed either rejection or coercion. Coercion is friendlier to
   producers that mint events in their local tz — the storage shape stays
   canonical UTC. The naive-datetime rejection remains hard (no honest
   default for an unknown wall clock).

4. **List→tuple coercion via `field_validator(mode="before")` on the
   container fields.** YAML/JSON arrays decode to Python `list`; without
   this coerce step the V-D-F2 closure (mutable container) creeps back in
   on the JSON-ingest path.

5. **`_FORBIDDEN_CONTROL_CHARS` as a single `frozenset[str]` built from C0
   + bidi unions.** Faster than a regex match per char; declarative;
   trivially extensible.

6. **Fence module lives under `tests/fence/`, not `tests/unit/transforms/`.**
   The story explicitly named `tests/fence/test_transforms_module_purity.py`
   and the existing `tests/unit/test_pyproject_fence.py` lives at unit-tier.
   Created the new directory; added empty `__init__.py`.

### Lessons (for cross-story `_lessons.md` consideration)

1. **Class-level annotation ABCs do not block direct instantiation on
   their own.** `Probe(ABC)` works because of `@abstractmethod` on `run`.
   When the contract surface is *all data attributes* and the story
   forbids `@property @abstractmethod`, `__new__` is the clean way to
   enforce abstractness. Use it sparingly — only when the alternative
   would be mixing two declaration patterns the story already pinned to
   one.
2. **Pydantic's `frozen=True` freezes attribute *reassignment*, not
   container mutation.** Recurring lesson: always use `tuple[...]` (or
   `frozenset[...]`) for aggregate fields. List-input ingest still
   works through a `field_validator(mode="before")` coerce step.
3. **The `_forward.py` shim is honest framing, not a placeholder hack.**
   `_placeholder: bool = True` fields anticipate future removal — that's
   churn. An empty Pydantic shell anticipates additive widening — that's
   stable. Same logical position; very different change-cost downstream.
4. **`make fence` standalone fails locally because pyproject's `addopts`
   carry `--cov-fail-under=85`.** CI uses `pytest -o "addopts="` to
   neutralize this. For local runs, `--no-cov` mirrors CI semantics.
   Documented in CLAUDE.md but easy to trip over.
