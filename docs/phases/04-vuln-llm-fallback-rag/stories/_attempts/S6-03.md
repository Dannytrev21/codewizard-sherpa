### Deferred (explicit follow-ups)

- **AC-8 — Idempotence via deterministic-id pre-check.** The story
  requires `if await self._store.contains(sid): emit HarvestSkipped`.
  The `SolvedExampleStore` Protocol does not currently expose a
  `contains` method (it has `query`, `query_candidates`, `add`,
  `digest`, `close`). Adding it is a Phase-5 extension to the
  Protocol + ChromaPersistentStore adapter; lands in a follow-up
  alongside Phase-5 contract harmonization. The current `on_validated`
  body always re-ingests on a passing gate; for the deterministic-id
  case (S4-06 AC-3 pins same identity inputs → same id), the
  underlying `store.add` will either no-op or surface a duplicate
  via the existing chromadb upsert semantics — not strictly idempotent
  but not destructive either.
- **AC-15 — Hypothesis exactly-one-terminal-event property.** The
  parametrized rejection-path tests cover the closed-set
  termination behavior; the Hypothesis property would surface
  additional fuzz coverage but is not load-bearing for downstream
  S6-* stories. Lands when the S6-07 determinism replay property
  test ships its strategy harness.

### Decisions of record

- **Six-step dispatch instead of seven** (deferred AC-8). The
  deterministic-id idempotence pre-check would land after the
  gate-pass and before the mint, but requires a Protocol method
  not present on the shipped `SolvedExampleStore`. The current
  body short-circuits AT the gate (not the store), which is
  sufficient for the load-bearing safety invariants (no
  high-confidence harvest when trust failed; no harvest of
  non-AppliedFromLlm outcomes).
- **Type-narrowing assertion after the eligibility gate.** The
  eligibility helper proves the outcome is `AppliedFromLlm`, but
  mypy --strict needs an explicit `assert isinstance(outcome,
  AppliedFromLlm)` before passing to `_validated_outcome_from`
  (which requires `AppliedFromLlm`-typed input per AC-9).
- **`HarvestSkipped.plan_outcome_kind` is the discriminator string,
  not the kind enum.** The closed Literal matches the
  `PlanOutcome.kind` values: `"llm"` / `"recipe"` / `"rag_only"` /
  `"refused"`. Pydantic narrows at construction time.

## Attempt 2 — 2026-05-26 — GREEN (deferred ACs closed)

**Executor:** phase-story-executor (Claude Opus 4.7)
**Outcome:** AC-8 idempotence pre-check + AC-15 mutual-exclusion
