### AC-18 honest framing (Rule 12)

The story Notes claim "httpx and requests ultimately funnel through
`socket.create_connection`". That is true for **sync** httpx (and for
stdlib `urllib`/`urllib3`) but **not** for **async** httpx — `httpcore`'s
async backend uses `anyio.connect_tcp` which delegates to
`asyncio.BaseEventLoop.create_connection` → `loop.sock_connect` on a raw
socket. The Phase-4 wrapper is therefore a sync-path defense; async paths
are covered by S3-02's `pinned_to(...)` envelope and ADR-0005 layers 2–4
(OS firewall, nightly drift, native-extension import-linter).

I split AC-18 into two tests rather than weakening it:

1. `test_sync_anthropic_sdk_does_not_bypass_wrapper` — sync `Anthropic`
   pointed at `192.0.2.1:80` proves the SDK funnels through our wrapper
   in the sync transport (the case the wrapper actually defends).
2. `test_async_httpx_bypass_is_a_known_residual` — pins the structural
   fact that `asyncio.BaseEventLoop.sock_connect` exists, so a future
   closure that hooks asyncio's path will deliberately update this
   assertion rather than silently widening the gap.

This is consistent with the story's own residual posture under "Notes
for the implementer" and ADR-0005's defense-in-depth framing.

### Refactor decisions

- `_is_admitted` pure helper landed as a green-path requirement
  (AC-27), not a refactor — separates the allow/deny algebra from the
  imperative shell that reads the `ContextVar`.
- `_parse_host_port` factored out so AC-28's malformed-input
  parametrization can target one function with one explicit exception.
- No `_WARNING_IDS` catalog: `egress_guard.py` raises an `Exception`
  and `EgressGuard` does not emit structlog events. The Phase-1
  ADR-0007 catalog convention only applies when a module emits
  `^[a-z][a-z0-9_]*\.[a-z][a-z0-9_]*$`-shaped event IDs (story
  Refactor §"Only add `_WARNING_IDS` if the module actually emits
  structured events").
