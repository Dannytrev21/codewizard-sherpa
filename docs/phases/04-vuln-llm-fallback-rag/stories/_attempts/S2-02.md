### Refactor decisions

- **Naming collision resolved.** The story's AC-12 names the event class
  `CanaryCollision`, but AC-5 also names the `CanaryResult` variant
  `CanaryCollision` — same name in the same import space. I renamed the
  *event* class to `CanaryCollisionEvent` (variant keeps the AC-5 name
  `CanaryCollision`); the on-the-wire `event_type` discriminator value is
  still `"canary_collision"` per AC-12. Documented inline in
  `plugins/events.py::CanaryCollisionEvent` docstring.
- **Default `nonce_source` is the raw `lambda: HexNonce(secrets.token_hex(16))`** form, not the `parse_hex_nonce(...).unwrap()` form. The story's AC-7 explicitly admits either — `secrets.token_hex(16)` is guaranteed to produce 32 lowercase hex chars so the raw cast is sound. Inline docstring on `_default_nonce_source` documents the guarantee.
- **Per-source-kind dispatch is a dict lookup, not a `match` ladder.** ADR-0013's caps live in `_TRUNCATION_CAPS: Final[dict[SourceKind, int]]`; adding an eighth source kind is one `Literal` member + one dict row + the AC-3 dict-vs-Literal coverage test fails loudly. No `assert_never` ladder anywhere.
- **`_FENCE_SOURCE_KIND` duplication on the event side is intentional.** Importing `SourceKind` *into* `plugins/events.py` would invert the layering — `plugins/events` would depend on `fallback/fence`. The two `Literal` definitions stay in sync via the AC-3 import-time check on the fence side and the AC-12 round-trip test on the events side; either side drifting fails loudly.

### What worked / what to remember

- **Reading sibling S2-01's `_attempts/S2-01.md` first** named the two pre-existing local-env failures explicitly, so they didn't blow up the verdict.
- The Hypothesis strategy must *construct* the delimiter for the chosen nonce; a bare `st.text()` would never reach the escape case at 2⁻¹²⁸. Cross-cutting lesson — apply when canary-style invariants depend on guessing an unguessable token.
- AST allowlist (over a name-resolver) beats both source-substring matching and a denylist: it fails closed and survives refactors.
