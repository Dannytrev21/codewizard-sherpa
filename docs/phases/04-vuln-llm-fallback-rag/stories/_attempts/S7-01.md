### Decisions of record

- **Plugin loaded via `importlib.util.spec_from_file_location`.** The
  hyphenated slug `vulnerability-remediation--node--npm` is not a
  Python-identifier-valid module name. The plugin loader at
  `codegenie.plugins.loader` already uses this mechanism for the
  PLUGINS.lock-discovered slugs; the test harness mirrors it.
- **`sys.modules` registration before `exec_module`.** The
  `@dataclass(slots=True)` decorator requires the class's module to
  be in `sys.modules` at decoration time. The test loader registers
  the module under its synthetic name (`_test_fallback_plan_engine`)
  before invoking `exec_module`. Production loader does the same.
- **`Skipped(reason="registry_skipped")` for `RagOnlyApplicable`.**
  The Phase-3 `SkipReason` Literal is closed at `{"plugin_disabled",
  "registry_skipped"}`; the closest semantic match for "RAG returned
  a candidate but the recipe declined" is `"registry_skipped"`.
  Phase 5 may widen this Literal with a `"rag_only_applicable"`
  member; the adapter currently uses the most-defensible existing
  value.

### Refactor decisions

- **Projection is a free function, not a method.** Composition +
  functional core / imperative shell. The projector has no `self`,
  no `await`, no event_log access; testable in complete isolation
  from any `FallbackTier` instance.
- **Plugin-id + recipe-id constants are module-level `Final`.** The
  closed identifier set lives at the module-top so all four
  `Applied(...)` constructions reference the same canonical values.
