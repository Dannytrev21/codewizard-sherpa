### Refactor decisions

- **Kernel-tier `TzAwareDatetime`** — when `rag.models` originally owned the
  alias, importing `BudgetSnapshot`/`BudgetToken` via `fallback/__init__.py`
  triggered a circular import (`rag.models` → `fallback.plan_proposal`
  → `fallback/__init__.py` → `fallback.budget` → `rag.models`). Moved the
  alias to `src/codegenie/types/datetime.py` — a one-file kernel-tier home
  consistent with `codegenie.types.identifiers` housing
  `PackageManager`. This honors the story's "do not copy the check three
  times" guidance without paying the cycle cost.
- **No shared `FrozenModel` base** — repeated `model_config = _FROZEN_FORBID`
  inline per the codebase convention (40+ models in `transforms/outcomes.py`,
  every probe model, `vuln_index/models.py`, etc.). Rule 11 — match
  existing patterns.
- **`FailureModeTag` placement** — kept rag-local at the top of
  `rag/models.py`. The codebase has two competing precedents for closed-set
  `Literal`s: kernel-tier (`PackageManager`, `Ecosystem`) for cross-module
  primitives, and module-local (`NotApplicableReason`, `EscalationReason`
  in `transforms/outcomes.py`) for domain reason-taxonomies. A
  remediation-failure vocabulary is closer to the reason-taxonomy
  precedent. Per Rule 7, surfaced rather than averaged.

### Lessons for the next attempt

- A shared utility imported by both `rag.models` AND `fallback.budget`
  cannot live in either package — the canonical home is
  `codegenie.types/*`. The cycle only surfaces at runtime, not at mypy.
- `PrivateAttr` declarations on a Pydantic v2 model do NOT appear in
  `model_fields` — only in `__private_attributes__`. AC-18's three tests
  (default, serialization-exclusion, forged-marker-rejection) collectively
  pin the contract; relying on `model_fields` alone would have missed
  the capability-discipline guarantee.
- The L-4 lesson reproduced verbatim: `tests/unit/test_lint_imports_canary.py`
  fails when run via `pytest` directly on macOS unless the venv is on
  `$PATH`. Treat as environment hygiene, not a story regression.
