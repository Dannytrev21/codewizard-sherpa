### Implementation notes

- **Discriminator idiom — followed F2 exactly.** `Field(discriminator="kind")` matches
  the 7+ shipped unions already in the codebase (`indices/freshness.py`,
  `probes/_shared/scanner_outcome.py`, etc.). No `Discriminator("kind")` callable
  form needed; both are valid Pydantic v2 but `Field` is the settled convention.
- **`Self` import — used stdlib `typing.Self`** (Python 3.11+, present in `pyproject`
  `requires-python = ">=3.11"`) rather than `typing_extensions.Self` (ruff UP035
  flagged the latter). All other typing imports follow the same pattern.
- **Single mid-flight bug**: the mypy-exhaustiveness meta-test's `_src(omit)`
  generator initially produced `case` arms at 8 leading spaces; combined with
  the surrounding `textwrap.dedent`-bound template (8 leading spaces) the dedent
  collapsed cases to column 0 (under `match p:` which sat at column 4), producing
  a SyntaxError that mypy reported as `[syntax]` rather than the exhaustiveness
  diagnostic. Fixed by emitting arms at 16 leading spaces so dedent leaves them
  at column 8 (matching the catch-all `case _ as never:` arm). Lesson recorded
  in `_lessons.md`. The story's verbatim TDD snippet had the same bug — surfaced
  as a follow-up for the story author (not editing the story; the actual code
  is correct).

### Refactor decisions

Walked the design-patterns refactor checklist:

- **Tagged union + Smart constructor + Make illegal states unrepresentable** —
  the central pattern this story enforces. Applied: `PlanProposal` is closed
  via `Field(discriminator="kind")`; `UnifiedDiff` and `SandboxedRelativePath`
  are smart-constructed via `Annotated[str, AfterValidator(...)]`; `frozen=True`
  + `extra="forbid"` makes mutation/extra keys illegal.
- **Functional core / imperative shell** — every validator is a pure module-
  level helper (`_validate_unified_diff`, `_validate_sandboxed_relative_path`,
  `_extract_diff_paths`); the model's `@model_validator` is the only shell.
- **Single-source the config (F15)** — `_FROZEN_FORBID: Final[ConfigDict]`
  pulled to module scope, referenced by all four variants.
- **Named-constant the magic numbers** — `_MAX_DIFF_BYTES = 65_536` and
  `_MAX_RATIONALE_CHARS = 2048` lifted out with docstrings naming the ADR-0001
  + synthesis-ledger 32 KB → 64 KB upgrade rationale.
- **NewType vs Annotated** — `UnifiedDiff` / `SandboxedRelativePath` are
  *deliberately* `Annotated[str, AfterValidator(...)]` (not `NewType`s)
  because validators must fire on every Pydantic construction; documented
  in module docstring + Notes-for-implementer §2.
- **Deferred**: `PlanProposalRefuse.reason` stays an inline `Literal` per F16
  (three members; promote to `StrEnum` only when multi-site branching emerges).

No anti-patterns introduced: no primitive obsession (every domain field uses
its newtype), no anaemic data classes (every variant carries semantic
identity via `kind`), no hidden state, no `Any`.
