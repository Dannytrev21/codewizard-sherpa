### Decisions of record

- **Filter owns the event, not the retriever.** AC-3 explicitly assigns
  emission to the filter (`self.event_log.emit_internal(...)`). The
  retriever had a placeholder emission (only ``count``); removing it
  prevents double-emission when the filter does its own.
- **`embedding_model == model_digest` comparison via underlying str.**
  `SolvedExample.embedding_model` is `ModelId` (NewType[str]); the
  embedder's `model_digest()` returns `BlobDigest` (NewType[str]).
  Both wrap `str`; the production convention is that the record's
  `embedding_model` field carries the BLAKE3 digest hex. Comparing via
  `str(...)` keeps mypy --strict clean while preserving the
  comparison's semantic correctness.
- **`object.__setattr__` for the cache slot.** The frozen-dataclass
  lazy-cache idiom: `_current_model_digest: BlobDigest = field(init=False)`
  + `__post_init__` setattr bypass. Mirrors the Python documentation's
  prescribed pattern for cached fields on frozen dataclasses.

### Refactor decisions

- **No `ModelDigestFilter` ABC.** The filter is a single concrete class
  satisfying a Callable shape. Inheritance would be premature; the
  Callable Protocol implicit in `S5-01.model_digest_filter` is the
  contract.
- **`sample_stale_model` is one digest (not a list).** AC-3's
  fixed-shape, audit-volume-bounded payload — a representative stale
  digest is enough for triage. Operator runs `codegenie rag rebuild`
  to scrub all stale records.
