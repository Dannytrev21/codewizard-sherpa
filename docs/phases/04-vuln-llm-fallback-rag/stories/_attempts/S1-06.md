### Refactor decisions

- **No new design patterns introduced.** The story is a one-shot config edit
  + a shape test mirroring the Phase-3 precedent (Plugin/Registry adjacent —
  import-linter is itself a contract registry). Pattern reuse: same shape-
  test convention as Phase-3 / Phase-7 (Rule 11).
- **D2 source-of-truth coupling preserved**: expected forbidden/source sets
  derived from the fence constants in `tests/fence/test_pyproject_fence_phase4.py`
  via `from … import …`, never re-typed as string literals — a future fence
  narrowing/widening immediately moves this test's expectations.
- **AC-7 deferred (recorded)**: the shape test is the always-on guard; live-
  fire would need a separate tmp-pyproject + `lint-imports` subprocess
  invocation that the story itself flags as brittle.

### Lessons for cross-story log

- The C4 cross-story-reconciliation hazard the validator flagged was already
  closed by earlier work (the Phase-3 / Phase-7 contracts were updated to the
  post-S1-05 SDK list when S1-05 landed). Always verify a hazard is still live
  before treating its remediation as in-scope — the story may have been
