### Refactor decisions

- **Specification pattern.** `is_app_layer` is the named rule the gate *and* S6-01 both reach for. Kept as a module-level pure function, not a static method — matches the codebase's "functional core / imperative shell" convention.
- **Facade Protocol, not adapter family.** `ProvenanceClassifier` is a Phase-4 facade port over `assemble_provenance`, deliberately distinct from the production `VulnProvenanceAdapter` hexagonal port. The story's C1 hardening pin: do not fork the primitive.
- **Lower-case discriminator values are the contract.** The gate stores and emits `provenance.kind` strings (not isinstance branches over variant classes); production ADR-0033 lower-case sum-type discipline.
- **Two-field gate, no state.** `@dataclass(frozen=True, slots=True)` with exactly `classifier` + `event_log`. AC-8's dataclass-field fence makes any cache / counter / retry-state addition a build break.
- **`EventLog._stamp` placeholder pattern.** The gate constructs `ProvenanceClassified(timestamp=datetime.now(UTC))`; `EventLog.emit_internal` calls `_stamp(event)` which overwrites the timestamp with the log's injected clock before bytes hit disk. Avoids dragging a clock dependency into the gate while satisfying the typed `timestamp: datetime` field at construction time.
