### Design pattern reinforcements applied

* **Newtype identifiers** (CLAUDE.md load-bearing commitment): `AttemptId` / `PromptDigest` / `ResponseDigest` instead of raw `str` — three new identifier sites x rule-of-three.
* **Smart constructor + immutability:** `AttemptAnchor` is Pydantic `frozen=True, extra="forbid"`; `extras` is forcibly converted to `MappingProxyType` via `model_validator(mode="after")` so post-construction mutation raises `TypeError`.
* **Tagged union discipline:** `plan_proposal_kind` literal pinned to `PlanProposal` discriminator tags via a dedicated fence test — extension-by-addition machine-enforced.
* **Functional core / imperative shell:** `anchor_writer.write` is a single pure-I/O function (no class, no DI surface — Rule 2 first-use); refusal anchors written inside `run`, success anchors deferred to `finalize_success_anchor` for the eventual Phase-5 caller.
* **Schema-version-as-dam:** `Literal[1]` + fence-gated coexistence-test-existence requirement makes any future bump *force* the migration discipline (not just docs).
