# Attempt log — S2-05 `LlmInvocationGuard` + `BudgetToken` capability issuer

## Attempt 1 — 2026-05-24 — phase-story-executor — GREEN

### Outcome

The Phase-4 LLM financial circuit breaker lands as four collaborating
pieces:

- [`src/codegenie/fallback/budget_token.py`](../../../../../../src/codegenie/fallback/budget_token.py)
  — the new home for `BudgetToken` (Pydantic `frozen=True, extra="forbid"`,
  four fields: `id: BudgetTokenId`, `precharged_tokens: TokenCount`,
  `precharged_dollars: Decimal`, `issued_at: TzAwareDatetime`). Splitting
  the capability into its own submodule is the **load-bearing structural
  choice** of this story: it gives the `import-linter` `forbidden`
  contract (AC-11) a module-level granularity to operate on, so the
  "two-frame discipline" can be enforced statically rather than by
  convention.
- [`src/codegenie/fallback/budget.py`](../../../../../../src/codegenie/fallback/budget.py)
  — refactored to ship `BudgetSnapshot` (the projection Phase 5 will
  consume across retries), `BudgetExceeded` (structured typed exception
  with `reason: Literal[...]` and per-reason numeric typing — `int` for
  the two token-cap reasons, `Decimal` for `workflow_max_dollars_exceeded`,
  no `int | Decimal` sloppiness), `BudgetReconcileUnknownToken`
  (forged-token guard), and `LlmInvocationGuard` (the issuer / Circuit
  Breaker). The guard uses `__slots__` for cache-friendliness and stores
  the **whole** `BudgetToken` in `_outstanding: dict[BudgetTokenId,
  BudgetToken]` (one source of truth — parallel id→count + id→dollars
  dicts can desync; S2-05 §"Store the whole BudgetToken" pins this).
- [`src/codegenie/plugins/events.py`](../../../../../../src/codegenie/plugins/events.py)
  — five new `WorkflowInternalEvent` variants registered in both the
  `WorkflowInternalEvent` discriminated union AND the `_INTERNAL_CLASSES`
  tuple (`emit_internal` does `isinstance(event, _INTERNAL_CLASSES)` —
  unregistered events raise `TypeError`):
  `BudgetPrecharged`, `BudgetReconciled`, `BudgetReconciledDuplicate`,
  `BudgetCapExceeded`, `BudgetUnknownTokenReconcile`. Internal-variant
  count grew 21 → **26**. Event-vs-exception name collisions were
  resolved per the story's S2-05 hardening notes:
  - exception `BudgetExceeded` ↔ event `BudgetCapExceeded`
  - exception `BudgetReconcileUnknownToken` ↔ event `BudgetUnknownTokenReconcile`
- [`pyproject.toml`](../../../../../../pyproject.toml) — new
  `[[tool.importlinter.contracts]]` block named `"ADR-0010: BudgetToken
  is two-frame scoped"` (AC-11). Source modules enumerate every codegenie
  subpackage minus `codegenie.fallback.budget_token` (the forbidden
  module) — `import-linter`'s `forbidden` contract requires source and
  forbidden trees to be disjoint. The shape test
  [test_budget_token_scope.py::test_contract_source_modules_match_codegenie_tree_minus_budget_token](../../../../../../tests/fence/test_budget_token_scope.py)
  pins this list so a new `codegenie/<x>/` directory cannot silently
  develop a blind spot. The single whitelisted import edge —
  `codegenie.fallback.budget -> codegenie.fallback.budget_token` — is
  the issuer's necessary access to the capability type. S3-02
  (anthropic_adapter) and S6-01 (fallback tier) will each append their
  own `ignore_imports` line when they land, per the
  extension-by-addition pattern S1-05 / S4-01 / S4-03 also use.

### Conflicts surfaced (Rule 7)

1. **S1-04 vs S2-05 model shape.** S1-04 shipped `BudgetSnapshot` with
   field names `cap_tokens` / `cap_dollars` and a single-int
   `outstanding_tokens: TokenCount`. S2-05 prescribes `max_tokens` /
   `max_dollars` and `outstanding_tokens: dict[BudgetTokenId, TokenCount]`
   plus `remaining_tokens` / `remaining_dollars` computed projections.
   Picked S2-05's shape (the more recent + the one aligning with
   `LlmInvocationGuard(max_tokens=, max_dollars=)` per ADR-0010
   §Decision). Rewrote
   [tests/unit/fallback/test_budget_models.py](../../../../../../tests/unit/fallback/test_budget_models.py)
   to the new shape; 16 tests still cover happy + sad paths.

2. **S1-04 `_marker` PrivateAttr vs S2-05 AC-2 Note.** S1-04 shipped
   `_marker: Literal["budget_token"] = PrivateAttr(...)` and three tests
   pinning its presence + non-serialisation + forged-rejection. S2-05
   AC-2 Note explicitly **dropped** the marker — "a leading-underscore
   attribute is a Pydantic v2 private attribute, not validated, absent
   from the JSON schema, no defense against hand-forged dicts." Removed
   the marker and the three tests; the threat model now matches the
   arch §Design-patterns row 882 honest framing — the `import-linter`
   contract (AC-11) is the sole structural guard; in-process direct
   construction is forgeable and that residual risk is accepted.

3. **`import-linter` "Modules have shared descendants"** when
   `source_modules = ["codegenie"]` overlaps with
   `forbidden_modules = ["codegenie.fallback.budget_token"]`. Resolved
   by enumerating `source_modules` as the codegenie tree **minus** the
   forbidden submodule (every top-level codegenie subpackage as-package
   plus every non-budget_token sibling under `codegenie.fallback`). The
   shape test
   [test_contract_source_modules_match_codegenie_tree_minus_budget_token](../../../../../../tests/fence/test_budget_token_scope.py)
   pins the enumeration against the live filesystem so new top-level
   subpackages can't silently slip past.

### Refactor decisions (design-pattern lens)

- **Capability + Circuit Breaker** — `BudgetToken` is the capability;
  `LlmInvocationGuard` is the circuit breaker. ADR-0010's load-bearing
  pattern; nothing speculative added.
- **Smart constructor** — `LlmInvocationGuard.precharge` is the sole
  mint site for `BudgetToken` (mirrors S2-04's `PromptBuilder` sole-mint
  precedent for `TrustedPrompt`/`FencedPromptBody`). Direct construction
  is **forgeable** (arch §Design-patterns row 882 honest framing) — the
  `import-linter` contract is the structural guard, not data-shape.
- **Sum-type / closed Literal** — `BudgetExceeded.reason` is a three-
  member `Literal` (`per_call_max_exceeded`,
  `workflow_max_tokens_exceeded`, `workflow_max_dollars_exceeded`);
  same literal type is the discriminator of `BudgetCapExceeded` events,
  so a missing branch is caught at type-check time and reason-as-string
  fragility cannot regress.
- **Newtype substrate** — `BudgetTokenId` / `TokenCount` from S1-01 are
  used everywhere (raw `str` / `int` only appear in caller-facing
  constructor parameters before the `TokenCount(...)` cast).
- **`__slots__`** — `LlmInvocationGuard` carries hot-path state
  (precharge runs once per LLM call); `__slots__` keeps the per-instance
  footprint compact without changing semantics.
- **Functional core / imperative shell** — `running_total()` is a pure
  projection (no I/O, no event emission, no mutation); the impure shell
  is concentrated in `precharge` / `reconcile`.
- **Idempotence on identity** — `reconcile` is no-op on
  `token.id ∈ _reconciled_ids`; this gives Phase 5's retry envelope the
  contract ADR-0010 §Tradeoffs row 3 commits to ("duplicate reconcile
  calls must be safe").
