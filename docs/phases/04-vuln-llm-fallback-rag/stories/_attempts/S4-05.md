### Refactor decisions / design-pattern lens

- **Functional core / imperative shell.** `verify` is pure; emission lives at the caller (S5-01 retriever, integration-test shim today). The split preserves Rule 9 — predicate tests can encode WHY (membership equality) without mocking event sinks.
- **Newtype-bound boundary.** `record.provenance.event_chain_head` is already `ChainHead` at the type system; the empty-string defence (`if not head: return False`) is the defence-in-depth check for direct `ChainHead("")` casts that bypass S1-01's smart constructor.
- **Protocol with one method = Ports & Adapters.** Future Phase-3 spanning-log adapter is a separate concern (S5-01 if translation is needed); the verifier consumes a minimal capability. Resisted `current_head()` / `get_chain_segment()` per Notes §2.
- **No registry.** The verifier has one execution path. Adding a `cache_strategy` or `verify_all` batch is premature (Rule 2).
- **Event class follows the alphabetical `__all__` and `WorkflowInternalEvent` union convention** — same as S2-01/02/04/05/S3-02 precedents.
