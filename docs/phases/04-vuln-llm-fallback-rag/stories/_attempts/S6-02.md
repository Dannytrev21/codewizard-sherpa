### Design pattern reinforcements applied

* **Functional core / imperative shell:** `select_retry_summary` is a module-level pure free function unit-tested in isolation; the `_emit_rag_skipped_on_retry` private method is the imperative shell that consumes the helper.
* **Truthiness as the discriminator (no boolean-flag drift):** `bool(prior_attempts)` IS the predicate; `tests/fence/test_prompt_builder_signature.py` makes the "no `is_retry: bool` parameter" invariant machine-enforced (Arch §Anti-patterns avoided line 912).
* **Single source of truth for cross-links:** `tests/fixtures/adr_links.py` + `tests/fence/test_adr_links_resolve.py` — references resolve OR the fence fails. Catches the precisely-the-regression we just patched (lines 819+938+1057+1078 of `phase-arch-design.md` had drifted to `ADR-04-0003`).
* **AST-walking fences (defense in depth):** three new fences guarding `tier.py`'s "do not fence / do not pre-truncate" invariants + a fourth pinning `PromptBuilder.build`'s parameter surface. These guard against the regression vector named in the story (`is_retry: bool` flag, `summary[:N]` slicing, `self.fence.fence(...)` premature call) regardless of test coverage.
* **Defense-in-depth unreachable assert:** `select_retry_summary` raises `AssertionError("unreachable: ...")` on empty input — the `bool(prior_attempts)` guard already prevents this, but a future refactor that flips the predicate would silently `IndexError` without the assert.
