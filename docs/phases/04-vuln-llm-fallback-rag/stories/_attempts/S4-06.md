- **`src/codegenie/rag/ingest.py`** (new, ~239 lines):
  - `ValidatedPlanOutcome` — frozen + extra-forbid Pydantic projection
    carrying every stable input needed to build a `SolvedExample`
    (`query_text`, `plan_proposal`, `transform_digest`,
    `trust_outcome_digest`, `task_class`, `language`, `build_system`,
    `cve_id`, `advisory_digest`, `response_id`, `chain_head`). No
    `dict[str, Any]` escape hatch. Uses kernel `Language` /
    `PackageManager` / `TaskClassId` rather than stale `*Name` aliases.

    `_solved_example_id_for`, `_solved_example_from_outcome`. BLAKE3
    over canonical JSON of exactly stable record-identity fields
    (`cve_id`, `advisory_digest`, `transform_digest`,
    `trust_outcome_digest`, `embedding_model`); workflow-context fields
    (`workflow_id`, `chain_head`, `created_at`, `query_text`,
    `response_id`) are intentionally excluded.
  - `ingest_solved_example(...)` — keyword-only async shell. Calls
    `embedder.model_digest()` once, `embedder.embed(query_text)` once,
    builds the `SolvedExample` + `RecordProvenance` per the hardened
    S1-04 shape, calls `await store.add(example, capability)` once,
    returns the `SolvedExampleId`. **Silent**: never imports `EventLog`
    and never emits `SolvedExampleHarvested` (S6-03 owns the gate /
    emission).
  - The mint module is imported by alias only
    (`from codegenie.rag import _capability_mint as
    _capability_mint_module`) so symbol-level rebinding into
    `ingest.py`'s namespace cannot happen and the AST fence stays sharp.

  extension-by-addition seam. When the operator-curated harvest path
