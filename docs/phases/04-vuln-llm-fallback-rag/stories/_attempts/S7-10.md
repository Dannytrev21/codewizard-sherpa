### Rule-7 surface — `RecipeApplication` vs `PlanOutcome`

The story's AC-9 text references `RecipeApplication` as the return type of the Protocol's `__call__`. **`RecipeApplication` does not exist in `src/codegenie/`** — the shipped contract (ADR-04-0004) is `PlanOutcome`, which wraps the Phase-3 `RecipeOutcome`. Honoring the shipped contract per Global Rule 7 (don't blend contradictory shapes): the Protocol's return type is `PlanOutcome`. A future Phase-5 contract harmonization that introduces `RecipeApplication` would land as a sibling Protocol addition, not a silent type rename — surfaced here rather than averaged.

### AC-10 placeholder caveat (S6-01 GREEN-partial dependency)

Today's `FallbackTier.run` placeholder dispatch returns `Refused(reason="PROVENANCE_NOT_APP_LAYER")` BEFORE calling the leaf. So `leaf.invoke.assert_called_once()` would FAIL today — the leaf mock is never invoked. The story's AC-10 text mentions "mocked LeafLlm was invoked", which is unreachable until S6-01 GREEN-complete lands the full 9-step dispatch. This Attempt ships the load-bearing semantics (callable returns a typed PlanOutcome end-to-end through asyncio.run) and surfaces the deferred-leaf-assertion as a one-line follow-up — written into the test file's module docstring so a future reader sees the deferral without re-reading the attempt log.
